# Wind-turbine-pitch-gear-data

*Wind turbine pitch gear fault diagnosis research data*

To evaluate the adaptability and effectiveness of MEBAformer in real engineering scenarios, this case study conducts an application validation using vibration data from pitch gears, collected by the CMS system of a wind farm located in Gansu Province, China. The dataset originates from a MySE3.6-166 semi-direct-drive WT, as illustrated in Fig. which depicts the variable-pitch gearbox, drive motor, and vibration sensors installed on the turbine. The constructed dataset includes three states: normal, gear damage, and gear fracture, all of which are four-channel vibration signals.
